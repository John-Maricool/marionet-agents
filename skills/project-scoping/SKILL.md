# Project scoping

1. **Goal and users:** the business outcome and every user type (for marketplaces: customer, vendor, rider, admin or staff).
2. **Feature list per user type:** as outcomes ("rider sees assigned orders on a map").
3. **MVP cut:** must-have for launch vs. later. Be ruthless.
4. **Hidden work (always list):** authentication, admin panel, notifications, payments and refunds, app store setup and review, analytics, error monitoring, legal pages, QA, deployment, handover.
5. **Milestones:** each ends with something the client can see and approve.
6. **Effort as ranges** (e.g. 3-5 weeks), never single numbers; widen the range for unknowns.
7. **Assumptions and out of scope:** written explicitly (e.g. "client provides designs", "one payment provider").
8. **Risks:** third-party APIs, store policies, unclear requirements.
