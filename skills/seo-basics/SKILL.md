# SEO basics

## Keywords
- Match search intent: informational (how, what), commercial (best, vs, cost), transactional (hire, buy), local (near me, in Lagos).
- Prefer specific long-tail phrases a small site can win over broad, competitive terms.
- One primary keyword per page; group close variants on the same page.

## On-page
- Title about 60 characters with the keyword near the start; meta description about 155 characters.
- One H1; H2 and H3 that follow the reader's questions.
- Answer the main question in the first paragraph (helps featured snippets and AI answers).
- Internal links to related pages; descriptive anchor text.
- Images compressed, with alt text.

## Technical
- Indexable (no accidental noindex), XML sitemap, sensible robots.txt.
- Fast on mobile; check Core Web Vitals.
- HTTPS, no broken links, canonical tags on duplicates.
- Structured data where relevant (Organization, Article, FAQ, LocalBusiness).

## Local
Google Business Profile complete and consistent name, address and phone everywhere.

## Never
Keyword stuffing, copied content, buying links, hidden text.
